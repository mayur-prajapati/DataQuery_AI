# 🤖 DataQuery.AI — Developed by Mayur Prajapati

This Streamlit-based app uses Google Gemini AI to analyze datasets (CSV, Excel, TXT) and answer queries using Pandas, NumPy, and basic math logic.

## 🧩 Features
- Upload CSV, Excel, or TXT files
- Auto-detect date columns
- Run AI-generated or manual Python code
- Copy and download results easily

## 🧠 Tech Stack
- Python, Pandas, NumPy
- Streamlit
- Google Gemini API
